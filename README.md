# autopost-kit

**Scheduled publishing queue: time slots, relative delays, no double-send, manual requeue, pause and auto-pause on repeated failure. Storage and the publish function are injected.** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/autopost-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('autopost-kit');
const x = create({ /* opts */ });
```
